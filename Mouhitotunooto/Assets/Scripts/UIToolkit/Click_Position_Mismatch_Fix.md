# クリック位置とボタンの反応位置ずれ問題 - 修正内容

## 問題
画面のクリック位置とボタンの反応位置がずれている

## 原因
Panel Settingsの**Match値が0.5（バランス）**になっていたため、幅と高さの両方を考慮したスケーリングが行われ、実際の画面サイズとReference Resolution（960x540）の比率が異なる場合に、座標変換が正しく行われていませんでした。

## 解決方法

### Match値を0.0（幅基準）に変更

**修正ファイル**:
- `Assets/UI Toolkit/PanelSettings.asset`

**変更内容**:
- `m_Match: 0.5` → `m_Match: 0` (幅基準)

## Match値の説明

- **0.0 (幅基準)**: 画面の幅に合わせてスケーリング。縦長画面に対応しやすい
- **0.5 (バランス)**: 幅と高さの両方を考慮したスケーリング。アスペクト比が大きく異なる場合に座標ずれが発生しやすい
- **1.0 (高さ基準)**: 画面の高さに合わせてスケーリング。横長画面に対応しやすい

## 現在の設定

```
Scale Mode: Scale With Screen Size (1)
Reference Resolution: 960 x 540
Screen Match Mode: Match Width Or Height
Match: 0.0 (幅基準)
```

## 効果

Match値を0.0（幅基準）に変更することで：
- 画面の幅に合わせて一貫したスケーリングが行われる
- 座標変換がより正確になる
- クリック位置とボタンの反応位置が一致する

## 注意事項

- 幅基準のスケーリングでは、画面の高さが大きく異なる場合、上下に余白が生じる可能性があります
- もし高さ基準のスケーリングが必要な場合は、Match値を1.0に変更できます

## 追加の調整が必要な場合

もし問題が解決しない場合は、以下を確認してください：

1. **Reference Resolutionの確認**: 960x540が適切か確認
2. **実際の画面サイズとの比率**: EditorとWebGLで異なる画面サイズを使用している場合、追加の調整が必要
3. **UIDocumentの設定**: すべてのUIDocumentが同じPanelSettingsを参照しているか確認
